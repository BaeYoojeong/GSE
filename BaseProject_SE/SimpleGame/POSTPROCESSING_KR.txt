수정일: 2026-09-22

적용 경로
DarkAgeRenderer.cpp → PostProcessing::BeginScene → 월드 렌더링
→ PostProcessing::EndScene → 화면 합성 → HUD / 대화 / 기록 화면.

HDR 장면
장면 색상과 발광 성분을 별도 RGBA16F 렌더 타깃에 기록한다.
표면 색은 sRGB에서 선형 공간으로 변환하며 광원의 밝기는 1.0을 넘는 HDR 값으로 유지한다.
광원 중심부와 발광 버퍼에 같은 방출 에너지를 사용한다.
캐시된 메시의 재생성 없이 emissionScale uniform으로 발광 성분만 부드럽게 흔든다.
비발광 표면은 이 밝기 변화의 영향을 받지 않는다.

모닥불과 등불
모닥불은 크고 넓은 발광 사각형과 세 단계의 높이 변화 대신 작은 계단형 불꽃 여러 개로 표현한다.
불꽃 주변의 빛무리는 별도 월드 도형으로 만들지 않고, 화면에 렌더링된 발광 성분에서 Bloom으로 만든다.
등불은 불투명한 틀과 작은 유리·심지의 발광 부분을 나누어 표현한다.
창문·촛불·전승자의 발광 장식도 동일한 Bloom 경로를 사용한다.
빛을 내지 않는 불투명 물체는 발광 타깃을 검정으로 덮어 뒤쪽 광원을 가린다.

Bloom 단계
1. 가려짐까지 반영된 발광 타깃의 각 원본 픽셀에 부드러운 밝기 임계값을 적용한다.
2. 정확한 2×2 texel을 평균하여 절반 해상도의 발광 영상을 만든다.
3. 1/2, 1/4, 1/8, 1/16 해상도로 내려가며 텐트 필터와 수평·수직 Gaussian blur를 적용한다.
4. 네 단계의 결과를 45%, 28%, 18%, 9%로 혼합하여 가까운 번짐과 넓은 빛무리를 함께 만든다.
5. HDR 장면에 Bloom을 더한 후 노출과 필름 톤 매핑을 적용한다.

임계값은 발광 성분의 가장 밝은 색 채널을 기준으로 한다.
붉거나 주황색인 불씨도 추출되며, 발광하지 않는 밝은 벽·아이템·UI는 Bloom 원천이 되지 않는다.
필터의 가중치는 정규화하고, 각 패스는 서로 다른 입력 텍스처와 출력 버퍼를 사용한다.

비넷과 가장자리 블러
중심부는 원본 장면을 최근접 샘플링하여 픽셀 윤곽을 유지한다.
화면 밖으로 갈수록 별도로 흐린 장면을 smoothstep으로 점진적으로 혼합한다.
비넷과 블러의 시작·끝 범위를 독립적으로 설정할 수 있다.
적용 범위는 게임 뷰포트 기준이며 레터박스 여백을 포함하지 않는다.
HUD와 대화는 후처리 합성 이후에 그려 가독성을 유지한다.

기본값 — PostProcessing.h의 Settings에서 관리
HDR 노출: 1.12
Bloom 강도: 0.80 / 임계값: 0.45 / 부드러운 경계: 0.30
Bloom 블러 간격: 각 해상도 기준 1.25픽셀
비넷 강도: 0.30 / 중심 거리 적용 범위: 0.35~1.38
가장자리 블러 강도: 0.65 / 중심 거리 적용 범위: 0.65~1.18
가장자리 블러 간격: 절반 해상도 기준 1.6픽셀
중심 거리는 정규화 좌표 기준이며 화면 변의 중앙이 1, 모서리가 약 1.414이다.
장면은 500×350이며 Bloom 해상도는 250×175, 125×88, 63×44, 32×22이다.

비교 조작
F1: Bloom·비넷·가장자리 블러 전체 켜기/끄기.
F2: Bloom만 켜기/끄기.
F3: 비넷만 켜기/끄기.
F4: 가장자리 블러만 켜기/끄기.
F5 / F6: 노출을 0.05 단위로 감소/증가.
F7: 기본값 복원.
HDR 톤 매핑과 SDR 변환은 F1을 꺼도 유지하여 광원의 밝기가 바로 잘리는 것을 방지한다.
F1이 꺼져 있으면 F2~F4의 개별 설정을 켜도 연출 효과는 표시되지 않는다.

사용자 확인 항목
- 모닥불과 등불 주변의 빛 번짐이 F2 OFF에서 사라지고 광원 중심은 남는지.
- 나무·건물에 가려진 광원 부분이 Bloom을 만들지 않는지.
- 중앙 픽셀은 선명하고 가장자리만 점점 흐려지는지.
- F3과 F4가 독립적으로 동작하고 HUD·대화에는 영향을 주지 않는지.
- F5/F6 노출 변경과 F7 초기화, 창 크기 변경이 정상 동작하는지.

범위
내부 HDR 렌더링을 톤 매핑해 SDR 화면에 출력한다. Windows HDR10 출력은 구현 범위에 포함하지 않는다.
Bloom은 화면 공간의 빛 번짐이며, 주변 지형의 실제 조명이나 광원 그림자 계산은 아니다.
모든 셰이더는 Shaders의 vs/fs 파일이며 빌드 시 실행 파일 옆 Shaders 폴더로 복사된다.
버퍼는 해상도 변경 시에만 할당하고 종료 시 모두 해제한다.
빌드·실행·실제 렌더링 결과 확인은 사용자가 진행한다.
