
메시 캐시 / 외부 셰이더 — 2026-09-28 갱신

현재 메시 캐시는 MeshCache의 GPU 공유 아틀라스와 DiskMeshCache의 파일 캐시로 구성된다.
기존의 메시별 VAO/VBO 직접 Draw 경로는 RenderBatch의 인스턴싱 큐로 변경되었다.
모든 실행 셰이더는 기존처럼 Shaders 디렉터리의 독립된 .vs/.fs 파일이다.

GPU 상주: 최대 256개 / 아틀라스 최대 32MiB(장치 TBO 한도가 더 작으면 축소).
파일: %LOCALAPPDATA%\AshenInheritance\MeshCache\geometry-3
      해당 버전 디렉터리 최대 256MiB/4,096개.

모델/그림자/사각형은 생성 후 파일로 저장하고 재실행 때 로딩한다.
위치, 크기, 색상, 알파와 발광은 인스턴스 상태이며 매 프레임 전달한다.
체력바/재 파티클 등의 사각형 정점을 매 프레임 다시 생성하지 않는다.
새 형상이나 캐시 실패 시에는 생성이 발생할 수 있으며 로그에 이유/형상 키를 남긴다.
텍스트 텍스처는 현재 별도 메모리 캐시이며 메시 파일 캐시 대상이 아니다.

형상 생성 코드가 바뀌면 DiskMeshCache.h의 GeometryRevision을 올린다.
위치/색상만 다른 경우 키를 추가하지 말고 인스턴스 값으로 전달한다.
GPU 캐시가 가득 차면 큐가 참조하지 않는 메시를 LRU로 회수한다.
실패 시 큐를 먼저 flush하고 재시도하며, 최종 실패는 기존 스트리밍 경로로 그린다.
