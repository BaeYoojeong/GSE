## 1. 요구사항과 적용

| 사용자 조건 | 이번 구현 |
|---|---|
| 맵 크기는 현재와 비슷하게 | 768 단위 청크, 주변 5×5 로딩 유지. 지형 끝이나 지역 전환 키 추가 없음 |
| 마을은 NPC 거점 | (0,0), (1,0), (0,1)에 초기 마을. 기존 집·예배당·불씨·도로에 시장 가판대와 주민 추가 |
| 체력·자산·깨달음 목표 | NPC별 목표, 현재 행동, 체력/최대 체력, 동전, 물자, 깨달음, 약탈 성향 |
| PK와 약탈 가중치 | P로 비적대 주민 공격 허용. 약탈 성향과 자산·체력·목표를 연속 점수로 반영해 약탈을 선택 |
| 직업별 생활·거래 | 사냥꾼·약탈자·상인·구도자. 광장에서 재고·동전을 실제 이전하는 거래 |
| 계속되는 상태 갱신 | 실행 중 모든 등록 주민의 기록을 10Hz로 갱신. 청크 밖에서도 동일 생활 규칙 적용 |

PK는 현재 싱글플레이에서 플레이어가 NPC를 공격·살해하는 방식이다. 네트워크 플레이어나 서버 전투는 포함하지 않는다.

## 2. 바로 플레이하는 순서

1. 기존 `SimpleGame` 프로젝트를 빌드하고 실행한다. 실행 설정과 외부 셰이더 복사 경로는 유지한다.
2. 새 세계는 시작 불씨 근처에서 시작한다. 기존 세이브라면 위치를 보존하므로 상단의 현재 청크와 가까운 마을 방향을 따른다.
3. `V`로 주민 전체 현황을 열어 사냥·거래·약탈 수치가 변하는지 관찰한다. `[`와 `]`로 페이지를 넘긴다.
4. 금색 표식 상인에게 가까이 가서 `E`로 대상을 확인한다. `B`로 물자 구매, `N`으로 판매한다.
5. 마을 남쪽 들판의 사냥 대상은 `Space`를 누르고 이동하며 공격한다. NPC 사냥꾼도 같은 대상을 노린다.
6. `P`를 켜면 비적대 주민도 자동 조준 대상이 된다. 다시 누르면 해제된다. 적대 주민은 PK가 꺼져 있어도 반격할 수 있다. 주민은 사망 직후 부활하고 3초간 보호된다.
7. `G`로 주민에게 물자를 나누고, 대화 `1/2/3`으로 감정을 기록한다. 한 삶에서 같은 주민에게 반복 반영되지 않는다.
8. 플레이어가 죽으면 `R`로 다음 삶을 시작한다. 전승자는 사망한 청크의 안전한 서쪽 휴식 공간에서 태어나 거점에서 생활한다.
9. `F8` 저장 후 종료/재실행하여 주민 재산·사망·전승 기록이 이어지는지 확인한다.

| 키 | 행동 |
|---|---|
| 방향키 | 이동 |
| Space 유지 | 사거리와 시야 조건에 맞는 가까운 대상에게 자동 발사 |
| E / Esc | 대화 열기/닫기 |
| B / N | 선택한 상인에게 물자 구매 / 판매 |
| G | 가까운 주민에게 물자 1개 나눔 |
| P | PK 전환, 전환 시 비행 중 플레이어 발사체 제거 |
| V | 전체 주민 현황 열기/닫기 |
| [ / ] | 주민 현황 이전/다음 페이지 |
| Tab | 기존 삶의 기록 |
| 1 / 2 / 3 | 대화에서 희망 / 두려움 / 분노 표현 |
| R | 사망 저장 성공 후 다음 삶 |
| F8 | 수동 저장 |
| F1~F7 | 기존 HDR/Bloom/비넷/블러 조절 유지 |

대화와 기록 창은 시간을 멈추지 않는다. 이동/공격 입력만 차단하며 NPC와 적은 계속 활동한다. Alt+Tab으로 게임 창이 포커스를 잃었을 때는 기존 앱의 갱신 중단 정책을 유지한다. 앱을 닫은 동안의 오프라인 경과 시간은 계산하지 않는다. 주민 시뮬레이션은 프레임 경과 시간을 누적하며, 긴 멈춤 뒤 한 프레임에서 최대 0.5초만 따라잡는다. 버린 시간은 `society_time_cap` 이벤트에 기록한다. 기존 플레이어 물리의 0.05초 상한과는 별도다.

## 3. 주민 구성과 판단 규칙

초기 마을마다 사냥꾼 2명, 약탈자 1명, 상인 2명, 구도자 1명으로 총 18명이다. ID 1~18은 세계 최초 생성 때만 배정된다. 사망한 주민은 같은 ID로 즉시 부활한다. 새로운 주민의 지속적인 유입은 플레이어의 죽음으로 생성되는 전승자에서 발생한다.

| 직업 | 기본 행동 | 생활 순환 |
|---|---|---|
| 사냥꾼 | 남쪽 사냥터 이동과 공격 | 사냥 → 물자/동전 → 귀환·판매 → 체력 회복/다음 사냥 |
| 약탈자 | 재산이 많은 비약탈 주민을 추적 | 접근 → 공격·동전 이전 → 대기·귀환 → 다음 약탈 |
| 상인 | 광장에 머물며 물자 거래 | 사냥꾼에게 매입 → 주민/플레이어에게 판매 |
| 구도자 | 거점 동쪽에서 수련 | 물자 사용·회복 → 깨달음 누적; 빈곤·물자 부족 시 사냥 |

공통 판단은 치명 피해 시 즉시 부활, 반격/긴급 회복, 다섯 후보의 가중치 비교로 구성한다. 직업은 기본 선택을 정하고, 상태와 목표가 우선 행동을 바꾼다. 깨달음은 이번 버전에서 누적 수치와 기록으로 표현하며 대규모 스킬 트리는 아직 없다.

초기 약탈자는 weight 0.92, 나머지 초기 주민은 0.03~0.13이다. 현재 weight는 약탈 행동 점수에 연속적으로 반영한다. 고정 0.6 임계값 대신 휴식·사냥·약탈·거래·수련의 효용을 비교한다. 정확한 점수와 전이는 추가 명세 1.3을 따른다.

NPC 이동은 기존 생성기가 확보한 중앙 십자 도로와 남쪽 열린 들판을 따른다. 초기 주민과 전승자의 생활 범위는 자신의 거점 청크다. 전투 중 플레이어 추격은 실제 장애물 충돌 검사와 청크 경계 제한을 사용한다. 여러 마을을 잇는 상단·이주는 후속 범위다.

휴식은 서쪽, 거래는 중앙, 수련은 동쪽의 여러 후보 자리로 분산한다. 각 NPC는 다른 주민의 현재 위치와 예약 목적지를 고려하고, 도로 이동에는 여러 통과 위치를 사용한다. 32단위 이내 주민은 주변 셀을 비교해 간격을 확보한다. 사냥은 슬롯당 최대 2명만 예약하며 몬스터 양쪽의 서로 다른 위치에서 공격한다. 시장 밖의 거래 상대도 계획에 포함하지만 재산 교환은 양쪽 모두 광장에 도착해야 가능하다.

## 4. 체력·경제·전투 규칙

| 항목 | 현재 추가 수치 |
|---|---|
| 초기 주민 체력 | 90 / 최대 체력 90 |
| 강한 몸 목표 | 물자 사용 시 최대 체력 +1, 최대 150 |
| 서쪽 휴식 장소 회복 | 목적지 도착 후 초당 7, 최대 체력까지 |
| 일반 주민 초기 동전/물자 | 24 / 2 |
| 상인 초기 동전/물자 | 80 / 12 |
| 플레이어 초기 동전 | 최초 세계 시작 20, 다음 삶마다 재지급하지 않음 |
| 동전/물자 한도 | 1,000,000 / 99 |
| 상인 매입 / 판매 | 물자 1개당 2동전 / 3동전 |
| 주민 의사결정 | 상태 판단 0.1초 단위, 거래/수련 간격 6초 |
| 약탈 | 피해 14, 반격 피해 7, 동전 최대 6 이전, 다음 시도까지 24초 |
| 플레이어 상대 절도 | 근거리 동전 최대 3 이전, 10초 적대 상태 |
| PK 피격 후 반격 | 30초 적대, 근거리 피해 12, 간격 1.5초 |
| 사냥 대상 | 거점당 4슬롯, 체력 60, 처치 후 최소 2초 대기와 안전 배치 검사; 점유 중 추가 대기 |
| NPC 사냥 | 피해 15/1.1초, 성공 시 물자 2·동전 3·깨달음 1 |
| 플레이어 사냥 | 기존 발사체 피해, 성공 시 물자 2·동전 3·XP 12 |

거래와 약탈은 한쪽 자산을 차감한 뒤 다른 쪽에 같은 양을 더한다. 재고, 잔액, 소지 한도를 통과해야 거래한다. 돈의 신규 유입은 세계 최초 지원과 사냥 보상으로 명시한다. 물자는 최초 배치/채집/사냥에서 생기고 회복·나눔·불씨 복구에 사용된다. 거래 자체가 물자나 돈을 복제하지 않는다.

약탈 대상은 사망할 수 있다. 주민을 죽이면 보유 동전/물자를 공격자에게 소지 한도 내에서 한 번 이전한다. 한도를 넘는 나머지는 사망 기록에 남으며 이번 버전에는 시체 수색 UI가 없다. 일반 몬스터 처치와 주민 PK 보상을 분리해, 주민 처치로 기존 지역 슬롯 보상을 중복 생성하지 않는다. 주민은 남은 자산으로 부활하며 초기 재산을 다시 받지 않는다.

비적대 주민을 때리면 악명 +5, 최대 100이다. 악명은 현재 HUD/저장 지표이며 아직 경비대·법정·거래 가격 변경을 연결하지 않는다. PK를 끄더라도 이미 적대해진 상대의 반격은 종료되지 않는다. 약탈 활동 중인 주민은 적대 대상으로 표시된다.

기존 채집은 일회성이다. 일반 적은 5초 리젠으로 변경하며 리젠 때 이전 드롭을 정리하고 보상 슬롯을 초기화한다. 사냥 대상은 최소 2초 뒤 해당 슬롯 영역의 다른 후보 위치에 배치한다. 모든 슬롯이 죽어도 대기를 건너뛰어 즉시 복구하지 않는다. 최초 생성과 로드에도 점유 검사를 적용하며, 아직 안전한 위치가 없는 대상은 숨기고 자동 조준에서 제외한다. 반복 사냥이 경제의 공급원이므로 영구 소진 규칙과 별개의 대상이다.

일반 적은 청크당 2슬롯을 유지한다. 생성 지점에서 벗어난 추적을 제한하고 목표를 잃으면 귀환한다. 주변 캐릭터와 간격을 확보하며, 같은 슬롯 Actor가 이미 있으면 추가 생성하지 않는다.

## 5. 죽음과 전승

플레이어 한 삶당 전승자 한 명이라는 기존 원칙을 유지한다. 전승 주민 ID는 `18 + LifeId`, `originLife`로 원래 삶과 연결한다. 원래 죽음 위치와 묘비는 기존 Memory에 남기고 생활 시작 위치는 같은 청크 서쪽 휴식 공간의 덜 붐비는 자리로 정한다.

| 기존 성향/감정 | 새 생활 역할 |
|---|---|
| 지키는 사람 | 사냥꾼, 강한 몸 목표 |
| 나누는 사람 | 상인, 깨달음 목표 |
| 불씨를 찾는 사람 / 길을 걷는 사람 | 구도자, 깨달음 목표 |
| 분노가 주 감정 | 약탈 성향 0.72와 재산 목표가 위 기본 목표보다 우선 |

기존 나눔·대화 이력과 관계를 이전한다. 비적대 전승자는 기존 치료/전투 지원을 유지한다. 전승 NPC도 즉시 부활하며 원래 LifeRecord/Memory와 주민 기록은 삭제되지 않는다. NPC의 죽음은 새 NPC를 자동 생성하지 않으며, 한 죽음 한 전승 규칙은 **플레이어의 삶**에 적용한다.

플레이어가 다음 삶을 시작해도 물자·동전은 유지한다. 기존의 매 삶 물자 3개 재지급은 없애 무한 나눔/판매 자원 생성을 막는다. 새 삶의 체력 회복과 기존 성장 유지 규칙은 그대로다.

## 6. 코드 책임과 데이터 수명

```text
Game
 ├─ WorldSociety: 모든 주민/사냥터의 영구 상태 + 10Hz 생활 규칙
 │   ├─ CitizenRecord: 직업/목표/위치/체력/재산/활동/적대/기원
 │   └─ HuntingGround: 체력/재생성 시간/공격 간격
 ├─ SceneGraph
 │   └─ 청크 → CitizenActor / QuarryActor / 시장·건물 등
 └─ 기존 플레이어·발사체·성장·전승·저장·렌더러
```

- `WorldSociety.h/.cpp`: 주민 상태, 거래, 약탈, 사냥, 기원 연결, 현황, 분석 이벤트.
- `WorldSocietyDecision.cpp`: 행동 점수, 거래 후보, 최대 2명 사냥 예약과 대상 선택.
- `WorldSocietySpatial.cpp`: 활동 목적지, 도로 이동, 주민 간격 유지, 사냥터 최초 배치·리젠, 개체 밀도 진단.
- `WorldSocietySave.cpp`: 주민/사냥터 직렬화와 범위·참조 유효성 검사.
- `SocietyActors.cpp`: 상태를 화면의 Actor로 반영하고 상호작용을 연결.
- `DarkAgeWorld.cpp`: 청크별 Actor 생성. 언로드는 주민 사망이나 데이터 삭제가 아니다.
- `DarkAgeCombat.cpp`, `ProjectileActor.cpp`: PK/적대 상태에 따른 타겟 판정과 피해 분배.
- `DarkAgeRenderer.cpp`: 직업 모델·색 표식·체력바·시장 모델. 새 형상은 기존 캐시/배치 렌더러 사용.
- `WorldScene.cpp`: 동전/악명/PK 상태, 마을 방향, 실시간 대화와 주민 현황·페이지.

Actor는 주민 사실의 별도 복제 저장소가 아니다. 렌더링용 위치·체력을 매 프레임 영구 기록에서 가져오며, 피해·거래는 WorldSociety를 통해 변경한다. 신규 Kind는 기존 enum 끝에 추가해 기존 형상 키의 번호를 바꾸지 않는다. 시간·동전·체력 같은 변화값을 모델 캐시 키에 넣지 않는다.

활성 청크 수는 늘리지 않는다. 등록된 주민 기록은 모두 갱신하므로 긴 세대 기록에서 CPU 비용은 증가한다. 현 단계는 초기 18명과 소수 전승자를 위한 프로토타입이며, 수만 명 실시간 시뮬레이션 성능을 검증했다고 표현하지 않는다. 세대가 커지면 지역별 인덱스, 낮은 빈도 갱신, 분할 저장을 측정 후 확장한다.

## 7. 저장·호환성

- 기존 경로 `%LOCALAPPDATA%\AshenInheritance\World_v1.txt`를 유지하고 내용 형식은 `ASHEN_WORLD_V4`다.
- V1/V2/V3 읽기, 기존 Region/Memory/Progression과 사회 기록 보존 후 누락된 신규 상태를 구성한다.
- 기존 파일은 최초 이전 시 `.pre-world-v4.bak`로 백업한다. 이미 존재하는 백업은 덮어쓰지 않는다.
- V4 안의 `SOCIETY_V2`에는 주민 전체, 사냥 지점, 플레이어 동전/악명, 누적 행동 수와 시뮬레이션 시간이 들어간다.
- 군집 수정은 저장 버전을 변경하지 않는다. NPC ID·재산·성장·전승과 몬스터 슬롯·체력·리젠 시간을 유지한다. 활동 목적지·사냥 예약·사냥터 후보 좌표는 재실행 시 계산하는 파생 상태다. 새 규칙에서 사냥터 위치는 옛 좌표와 달라질 수 있다.
- 기존 단일 파일 임시 작성 → flush → 원자 교체를 사용해 플레이어 사망과 전승 주민을 함께 커밋한다.
- NPC 사망/보상/부활은 메모리에서 즉시 반영하고 기존 5초 자동 저장 또는 F8/정상 종료 시 함께 저장한다. 비정상 종료 시 마지막 성공 저장 이후 변화는 되돌아갈 수 있다.
- 손상/미지원/중복 ID/잘못된 참조는 적용하지 않고 원본 덮어쓰기를 차단한다.
- V4가 전체 종탑 퀘스트 스키마 구현을 의미하지 않는다. 이후 구조 변경은 별도 버전 이전을 추가한다.
- 64MiB 단일 스냅샷 한도는 기존과 같다. 분할 저장은 후속 설계 조건이다.

## 8. 관찰·진단

`V` 화면은 청크 로딩 여부에 관계없이 모든 주민의 직업, 행동, 체력, 돈, 물자, 깨달음을 8명씩 보여준다. `E`는 선택 주민의 목표와 약탈 가중치, 기원, 재고를 자세히 표시한다. 주민이 떠나거나 사망하면 거래 시점에 거리·시야·생존·적대 상태를 다시 검사한다.

기존 프로파일 이벤트 파일에 `society`와 `society_summary` 범주를 추가한다. 거래, 약탈, 사냥, 죽음, PK 피격, 깨달음 주요 지점을 actor/target/amount/시뮬레이션 시간으로 기록하고, 주요 이벤트는 콘솔에도 출력한다. 10초 요약에는 생존 인구, 전체 동전·물자, 사회 갱신 CPU 합계/최대 시간을 남긴다. 전체 주민의 상태를 매 렌더 프레임 출력하지 않는다. 렌더러의 draw-call/캐시 로그는 계속 사용한다.

`population_spacing`은 10초마다 64단위 셀의 최대 NPC 밀도, 사냥터 슬롯·배치 대기, 실제 Actor 수와 중복 수를 콘솔과 이벤트 파일에 남긴다. `quarry_spawn_position`/`quarry_respawn`으로 배치 좌표를, `quarry_respawn_deferred`로 점유에 따른 보류를 확인한다. `monster_duplicate_prevented`는 중복 생성 요청을 막았다는 기록이며 실제 중복 수는 `duplicate_actors`로 판단한다.

## 9. 사용자 실행 검수표

아래는 실행 결과가 아니라 필요한 확인 절차다.

- [ ] 신규/기존 저장 양쪽에서 진입. 처음 18명과 기존 전승자 수가 합산되며 중복 생성되지 않는다.
- [ ] 방향키로 거점 3곳 왕복. 기존 청크 크기와 도로 이동, 건물 가림이 유지된다.
- [ ] V를 열고 60초 이상 관찰. 주민 사냥·귀환·거래·약탈·수련과 수치가 변한다.
- [ ] 멀리 이동해 시작 마을이 언로드된 뒤 V 관찰. 해당 주민의 생활과 재산이 계속 변한다.
- [ ] 상인 근처 E→B/N. 양쪽 물자·동전이 정확히 이동하고, 빈 재고/잔액 부족에서는 변경되지 않는다.
- [ ] PK OFF에서 일반 주민이 맞지 않는다. P→Space로 주민 전투, 반격, 사망, 전리품 1회 이전 확인.
- [ ] PK OFF에서도 약탈/적대 주민에게 반격 가능하며 P를 껐다고 상대 적대가 즉시 사라지지 않는다.
- [ ] NPC와 같은 사냥 대상을 공격. 처치 보상은 마지막 유효 공격에서 한 번, 최소 2초 뒤 안전한 자리에 재생성.
- [ ] 모든 사냥 대상을 처치해도 즉시 강제 생성되지 않고, 점유한 자리를 비우면 배치가 재개된다.
- [ ] 휴식·거래·수련의 활동 장소가 분산되고 일반 몬스터가 추적 종료 후 귀환한다.
- [ ] 여러 청크 왕복 후 `duplicate_actors=0`, 일반 적 수가 로딩 청크 수×2 이하인지 확인한다.
- [ ] 피해·거래·NPC 사망 이후 F8→재실행. 체력·재산·부활 횟수가 유지되고 주민이 중복 생성되지 않는다.
- [ ] 플레이어 사망→R. 전승 주민 1명 추가, 물자·동전 재지급 없음, 원래 삶과 관계 연결 확인.
- [ ] 전승 주민에게 나눔/감정 선택. 중복 반영 방지, 비적대 치료/전투 지원 확인.
- [ ] 대화/Tab/V 중 실시간 갱신, 입력 차단, Esc 닫기, Alt+Tab 복귀 시 입력 잔류 없음.
- [ ] 실행 로그에서 society 이벤트와 렌더링 카운터 확인. 전승자 증가에 따른 CPU 비용은 별도 측정.
