# 이미지 월드 지도·포탈·상인 상호작용

## 플레이 방법

1. 각 마을의 중앙 남쪽 길 `(384, 600)`에 있는 돌 아치 포탈 가까이에서 **E**를 눌러 활성화한다. 활성화하면 청록색 보석과 Bloom이 켜지고 지도가 열린다.
2. **M**으로 지도를 연다. 마을 이름 목록 대신 실제 청크의 지형·도로·집 배치를 그린 컬러 이미지 위에 현재 위치와 일곱 포탈을 표시한다.
3. 포탈 아이콘을 마우스로 클릭하고 오른쪽 **순간이동** 버튼을 누른다. **1~7** 선택 및 **Enter** 이동도 지원한다. 회색 포탈은 현장에서 활성화해야 사용할 수 있다.
4. 시장의 금빛 상인 NPC에게 가까이 가서 **E**로 상호작용하면 그 상인의 구매 화면이 열린다. 무기·물약·물자 선택 후 Enter/E 구매, N 물자 판매, Esc 종료다. I는 인벤토리로 전환한다.

B 상점 진입과 노점 오브젝트를 통한 원격 거래를 제거했다. 상인이 시장 안에 있고, 살아 있으며, 비적대 상태이고, 플레이어와 110단위 이내이며 길이 막히지 않아야 한다. 구매·판매는 E로 시작한 해당 NPC 세션에서만 허용한다. 거래 중인 상인은 응대하며, 다른 주민과 세계 시간은 계속 진행한다. 거리 이탈·사망·적대 전환 시 창을 닫는다.

## 지도 이미지와 입력

- `WorldMap::BuildImage`는 실제 게임 시드의 Biome/Hash, 청크 도로 규칙, 주민의 집 좌표로 520×390 RGBA 이미지를 만든다. 존재하지 않는 강·섬을 임의의 지형처럼 그리지 않는다.
- 생성 이미지는 GPU 텍스처로 보관한다. 보기 위치·배율·시드·집 배치가 같으면 다시 만들지 않는다. 드래그 중 기존 이미지를 재사용하며, 보기 변경 시 최대 120ms 간격으로 갱신한다. 주민 이사나 새 집 배치도 갱신에 반영한다.
- 렌더러는 기존 글자 마스크와 RGBA 이미지를 구분하며 배치 키에 샘플링 모드를 포함한다. 지도는 최근접 샘플링으로 픽셀 윤곽을 유지한다.
- 마우스의 윈도 좌표를 실제 프레임버퍼 크기로 보정한 뒤 게임 UI 1000×700 좌표로 변환한다. 레터박스 영역의 클릭은 무시한다. 아이콘 그리기와 클릭 판정이 같은 투영 함수를 사용한다.
- 지도는 플레이어 위치를 중심으로 열리는 이동·확대 가능한 창이다. 드래그로 이동하고 휠로 확대/축소한다. F는 현재 위치, G는 일곱 마을 개요로 돌아간다. 지도 범위는 일곱 마을에 고정되지 않는다. 상세 구조는 [OPEN_WORLD_KR.md](OPEN_WORLD_KR.md)를 참조한다.

## 포탈 규칙과 저장

포탈은 `WaypointActor`로 SceneGraph에서 제어한다. 활성/비활성 두 형상을 MeshCache에서 재사용한다. 발광은 기존 HDR/Bloom 경로를 사용한다.

`Waypoints`는 활성화 비트를 관리한다. 최초 활성화는 근접 거리·통행 경로·저장 상태를 검사하고 기록을 저장한다. 저장이 실패하면 활성화를 되돌려 다시 E로 시도할 수 있다. 이미 활성화한 포탈의 E는 지도만 연다.

이동 시 입력·발사체·대화·거래를 정리하고 대상 청크를 로딩한다. 포탈 주변에서 장애물과 NPC·적이 차지하지 않은 도착점을 찾는다. 공간이 없으면 이전 위치로 돌아간다. 정상 이동은 카메라·원점·NPC 프록시를 맞추고 짧은 도착 보호를 부여한 뒤 저장한다. 이동은 정수 청크 원점을 직접 바꾸고 작은 로컬 좌표로 배치하므로 멀리 이동해도 좌표 정확도를 유지한다. 임시 도착점 검사는 자동 저장을 일으키지 않는다.

월드 코어는 `ASHEN_WORLD_V8`, 포탈 구역은 `WAYPOINTS_V1`이다. 이전 V1~V7의 진행·지역·인벤토리는 해당 버전 규칙대로 유지하고 포탈은 미활성으로 시작한다. 전환 전 SQLite backup API로 `World_v1.txt.pre-waypoints-v8.sqlite3`를 생성한다. 활성화 상태는 종료·재시작·다음 삶에도 유지한다.

## 확인 범위

이번 작업에서는 사용자 선호에 따라 게임을 빌드하거나 실행하지 않았다. 소스·프로젝트 등록·좌표 수식·저장 분기를 정적으로 확인했다. 선택적 --self-test에는 이미지 결정성, 포탈 아이콘 클릭 좌표, 잠긴 포탈·원격 활성화 거부, 안전 도착, 상태 저장·재시작, V7 인벤토리 보존 전환 검사를 추가했다. --window-smoke에는 화면 좌표 보정·레터박스 거부 검사를 추가했다. 새 사용자 빌드 후 실행해야 하는 검사이며, 이번 작업에서 통과한 실행 결과로 간주하지 않는다.
